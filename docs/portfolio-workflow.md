# Alur mengisi Portfolio secara berkala

1. **Setelah UAT disetujui** (atau saat mockup selesai), buat entri di Dashboard > Portfolio.
2. Isi: Judul, Jenis (Proyek Klien / Contoh-Mockup / Proyek Internal), Terkait layanan, Tahun, Ringkasan.
3. Isi tiga bagian metode Rovan: Kondisi awal (baseline), Solusi, Hasil (bandingkan dengan baseline). Kosongkan Hasil bila belum ada angka nyata.
4. Upload gambar mockup (rasio 16:10, sekitar 1600x1000 px, WebP/JPG di bawah 300 KB).
5. Nama klien hanya dipublikasikan dengan izin tertulis. Tanpa izin, kosongkan kolom klien dan sebut jenis usahanya di ringkasan.
6. Simpan dengan "Tampilkan di situs" nonaktif (draft), tinjau, lalu aktifkan.
7. Opsional: tulis satu artikel di News sebagai studi kasus dan tautkan ke entri portfolio.
8. Tinjau portfolio tiap bulan: hapus yang usang, ganti mockup dengan proyek nyata bila sudah ada.
